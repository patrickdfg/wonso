# 원소 길드 · Element Guild

118개 원소를 창작 캐릭터와 연결해 배우는 한국어 웹앱입니다.

**사이트:** https://patrickdfg.github.io/wonso/

## 학습 흐름

1. 주기율표에서 원소를 선택합니다.
2. 캐릭터의 소품과 기억 문장을 실제 과학적 성질에 연결합니다.
3. 플래시카드를 뒤집어 이름과 기호를 확인합니다.
4. 캐릭터·성질·기호 퀴즈를 풀고 오답만 다시 복습합니다.

## 기능

- 118개 원소 / 118개 창작 캐릭터, 캐릭터 도감 검색
- 원소 특징, 쓰임, 계열, 원자 구조, 암기 문장
- 상세 화면 좌우 스와이프, 방향키, 이전/다음 버튼
- 1~20번, 1~36번, 전체 학습 범위
- 캐릭터→원소 / 기호→이름 / 이름→기호 플래시카드
- 외운 원소·복습 원소 저장, 범위별·유형별 퀴즈 최고 점수
- 한 번에 10문제, 오답 해설, 이번 오답만 재도전
- 빌드와 API 키 없이 실행되는 정적 HTML

`index.html`과 `assets/`를 함께 유지하면 됩니다. 학습 기록은 해당 브라우저의 localStorage에 저장됩니다. 다른 기기와 동기화되지는 않습니다.

## 자료와 표현

원소별 과학 자료 링크: [Royal Society of Chemistry 주기율표](https://periodic-table.rsc.org/).

캐릭터의 능력·색깔·장비는 기억을 위한 창작 비유입니다. 인체에 쓰이는 원소는 대개 화합물·이온 등 특정 형태이며, 그림은 실제 원소를 손으로 다루는 방법을 뜻하지 않습니다. 무거운 합성 원소는 연구 단계이므로 알려진 이름의 유래 등을 기억 단서로 사용했습니다. 원소 분류에는 자료별 차이가 있을 수 있습니다.

## 이미지

내장 이미지 생성 도구로 제작한 오리지널 캐릭터 아틀라스 6장입니다. `assets/characters-1.webp`부터 `assets/characters-6.webp`까지 순서대로 원자번호 1~20, 21~40, 41~60, 61~80, 81~100, 101~118을 담았습니다. 마지막 두 칸은 장식입니다.

제작 프롬프트의 공통 구조: “4열×5행의 판타지 치비 원소 모험가 아틀라스, 어두운 남색 배경, 인물마다 다른 의상과 원소 특성을 나타내는 소품, 글자 없이 규칙적인 격자 배치”. 수소는 가벼운 별빛 정찰병, 탄소는 흑연 망토와 다이아몬드 방패의 변신술사, 철은 붉은 혈액 보석을 가진 강철 기사 등 각 원소의 기억 문장에 대응하도록 개별 지정했습니다. CSS의 `atlasBounds`로 각 캐릭터 영역을 표시합니다.

## 배포

이 저장소에 이미 설정된 `main` 브랜치 기반 GitHub Pages를 사용합니다. `.nojekyll`로 정적 파일을 그대로 게시합니다. 기존 중복 사용자 정의 Pages 워크플로는 정리했습니다.

## 검증

Chromium에서 118개 원소와 표 좌표, 6개 이미지 로딩, 상세 화면 이동, 도감 검색, 카드 뒤집기와 빈 복습 목록, 새로고침 후 기록, 10문제 채점과 오답 재도전, 390px 모바일 너비 및 스와이프 이벤트를 확인했습니다.
